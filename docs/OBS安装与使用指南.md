# 视频录制与剪辑指南

## 一、OBS 安装

### 下载地址

- **官网**：https://obsproject.com/download
- **备用**：https://github.com/obsproject/obs-studio/releases

### 安装步骤

1. 双击下载的安装程序
2. 选择语言（中文）
3. 点击"下一步" → 选择安装目录 → 点击"安装"
4. 安装完成后，勾选"启动 OBS Studio"

## 二、OBS 配置

### 首次启动（自动配置向导）

1. **使用场景**：选择"仅录制屏幕"
2. **优化设置**：选择"优先录制质量"
3. **帧率**：选择 30 FPS
4. **分辨率**：保持默认（1920x1080）
5. 点击"应用设置"

### 输出设置

1. 菜单栏"文件" → "设置" → "输出"
2. 设置：
   - 录像质量：高质量
   - 录像格式：MP4
   - 录像路径：`D:\VoiceCare\videos\01_开发录屏`
   - 编码器：软件（x264）

### 音频设置

1. "设置" → "音频"
2. 确认：
   - 桌面音频：默认扬声器
   - 麦克风/辅助音频：默认麦克风
3. 测试：说话时看音量条是否跳动

### 场景与来源

1. **场景**：点击 + 号，添加"开发录屏"
2. **来源**：点击 + 号，添加：
   - 显示器捕获：录制整个屏幕
   - 音频输入捕获：录制麦克风
   - 音频输出捕获：录制系统声音

## 三、录制操作

### 开始录制

1. 点击右下角"开始录制"按钮
2. 或使用快捷键：Ctrl + Shift + R（可在设置中修改）

### 停止录制

1. 点击"停止录制"按钮
2. 文件自动保存到预设路径

### 录制技巧

1. **录制前**：关闭无关窗口，清理桌面
2. **录制中**：口述操作步骤，方便后期剪辑
3. **录制后**：立即重命名文件

## 五、视频剪辑（剪映）

### 安装剪映

- 下载地址：https://www.capcut.cn/
- 直接下载：https://download.capcut.cn/CapCut_1.2.0.exe

### 基础剪辑步骤

1. 导入录制的视频素材
2. 拖拽到时间线
3. 剪辑掉不需要的部分
4. 添加字幕（AI 自动识别）
5. 添加背景音乐（可选）
6. 导出：1080P，30fps，MP4

### 导出设置

- 分辨率：1920x1080
- 帧率：30fps
- 格式：MP4
- 码率：推荐

## 六、常见问题

### Q1：录制没有声音？
- 检查麦克风是否正确连接
- 在 OBS 设置中确认音频输入设备
- 对着麦克风说话，看音量条是否跳动

### Q2：视频文件太大？
- 降低输出分辨率
- 选择"中等质量"
- 使用 H.265 编码

### Q3：录制卡顿？
- 关闭其他占用 CPU 的程序
- 降低帧率到 24 FPS
- 使用硬件编码（如果有 NVIDIA 显卡）

### Q4：找不到录制文件？
- 在 OBS 设置中查看"录像路径"
- 点击"浏览文件"快速定位

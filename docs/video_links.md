## 录制流程

### 1. 录制前准备

- 清理桌面（关闭无关窗口）
- 检查 OBS 设置（录像路径、麦克风）
- 准备好要演示的内容
- 准备好录制脚本

### 2. 录制时

- 开场：自我介绍 + 演示内容
- 边操作边讲解
- 每步停顿 2 秒
- 结束：总结 + 下一步计划

### 3. 录制后

- 立即重命名文件（按命名规范）
- 检查视频质量（画面、声音）
- 移动到对应目录

## 视频剪辑流程

### 最终作品剪辑（罗元源负责）

1. **收集素材**：从各人电脑复制录屏文件到统一目录
2. **剪辑工具**：剪映（https://www.capcut.cn/）
3. **输出版本**：
   - 完整版：10-15 分钟（答辩用）
   - 精简版：5-8 分钟（初赛提交用）

### 剪辑结构

```
1. 开场（30秒）
   - 项目背景
   - 创新点介绍

2. 系统架构（1分钟）
   - 端云智架构图
   - 技术选型说明

3. 老人端演示（2分钟）
   - 看图说话
   - 故事复述
   - 语音信箱

4. 照护者端演示（2分钟）
   - Agent 简报
   - 风险看板
   - SHAP 解释

5. 技术亮点（1分钟）
   - 纵向基线偏离
   - 可解释 AI

6. 结束（30秒）
   - 团队介绍
   - 展望
```

## 注意事项

1. **视频不进 Git**：所有视频已加入 .gitignore
2. **命名规范**：统一使用 `日期_开发者_内容.mp4` 格式
3. **保存原始文件**：不要删除任何录屏素材
4. **定期检查**：每周检查一次视频文件是否完整

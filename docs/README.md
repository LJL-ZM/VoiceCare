# AI 面试准备助手

## 项目简介

AI 面试准备助手是一款帮助求职者准备面试的 Web 应用。通过自然语言问答，解答求职者关于面试的各种问题，提升求职成功率。

## 核心功能

- **智能问答**：语音/文字问答，解答面试问题
- **面试技巧**：提供面试技巧和建议
- **常见问题**：预设常见面试问题，一键查询

## 技术架构

- **前端**：HTML + CSS + JavaScript
- **后端**：FastAPI（Python）
- **AI**：盘古大模型

## 开发进度

- 第 1 天：后端 + 盘古对接 ✅
- 第 2 天：前端页面 ✅
- 第 3 天：联调 + 测试 ✅

## 创新点

1. **自然语言交互**：用户可以用自然语言提问，AI 智能回答
2. **预设常见问题**：一键查询常见面试问题，快速获取答案
3. **简洁高效**：无需注册登录，打开即用

## 社会价值

- 帮助求职者提升面试能力
- 降低求职门槛
- 促进就业
